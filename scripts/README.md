# Scripts operativos

| Script                   | Uso                                                                                                                                               |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`dev-db.sh`](dev-db.sh) | PostgreSQL local de desarrollo (`start`, `stop`, `status`), sin sudo ni tocar el del sistema. Atajos: `npm run db:local:start` / `db:local:stop`. |
